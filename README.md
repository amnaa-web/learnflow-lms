# LearnFlow LMS Demo — Vercel Fix

This version has the Vite entry point `main.jsx` and CSS at the project root to avoid errors if GitHub upload drops the `src` directory.

Upload ALL files from this directory to the repository root, NOT a parent folder. The repository must contain `index.html`, `main.jsx`, `styles.css`, `package.json`, `vite.config.js`, and `vercel.json` side by side.

Vercel settings: Framework `Vite`, Root Directory `./`, Build Command `npm run build`, Output Directory `dist`. Deploy after committing files.

This is an interactive web demo using local sample data and browser storage, NOT a real React Native app.
